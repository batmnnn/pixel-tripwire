# Pixel Tripwire

A frozen, pre-registered synthetic benchmark for hidden content in agent-to-agent chart images.
It was built for the Apart Research Swarm Alignment Hackathon 2026, Track 4.

- Report: [`study/report/report.pdf`](study/report/report.pdf)
- Public code: `study/pt/` (chart generation, rendering, raster tools, detectors, VLM prompts and parser, figures)
- Freezes, with SHA-256 hashes: `study/freeze/`
- Aggregate results: `study/runs/`
- Pre-registration: `study/PLAN.md`
- Deviations from it: `study/DEVIATIONS.md`

Withheld for dual-use reasons:
- encoders
- the reference decoder
- messages
- positive images
- raw VLM answers on positives

All code was written during the sprint, 7–9 Nov 2026.
